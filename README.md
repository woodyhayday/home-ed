# Home Education Online Resources Directory

In the making of the [Strew Home Ed App](https://strew.app), I've come across lots of great resources for home-ed parents and homeschoolers, (or worldschoolers, unschoolers, and all the wonderful variations of approaches to home education).
- This list is a work-in-progress collection of resources, if you have any good additions, please do PR me here, or drop me an email from the [Strew](https://strew.app/) homepage.
- There are so many ways to home-ed; I don't necessarily follow the curriculums or approaches mentioned here, so please do remember to try-for-fit, and see which suits you and your child best!
